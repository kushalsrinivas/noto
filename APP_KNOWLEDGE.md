# Haven AI — Technical Knowledge Base

## Overview

Haven AI (internal codename: `noto`) is an AI-powered voice notes and smart productivity app built with React Native and Expo. All AI processing runs entirely on-device using a local LLM (Qwen 2.5 0.5B) and Whisper for speech-to-text — no data ever leaves the user's phone.

**Bundle ID:** `com.kushalbhai.noto`
**App Group:** `group.com.kushalbhai.noto`
**Version:** 0.1.0
**EAS Project ID:** `2c26f785-bc13-4769-aac1-971f948ff241`

## State Management

The app uses **custom React hooks + AsyncStorage** (no Redux, no Zustand). Each entity has its own hook:

| Hook              | Storage Key                 | Purpose                                         |
| ----------------- | --------------------------- | ----------------------------------------------- |
| `useNotes()`      | `@noto/notes`               | CRUD for notes, sorted by `updatedAt` desc      |
| `useTasks()`      | `@noto/tasks`               | CRUD for tasks, toggle completion               |
| `useRecordings()` | `@noto/recordings`          | CRUD for audio recordings                       |
| `useFolders()`    | `@noto/folders`             | Folder management (pin, archive, lock, reorder) |
| `useOnboarding()` | `@noto/onboarding_complete` | First-run gate                                  |
| `useUserName()`   | `@noto/user_name`           | User's display name                             |
| `useAiMode()`     | `@noto/ai_mode`             | `"full"` or `"lite"` AI mode                    |
| `useUsageStats()` | `@noto/usage_stats`         | Telemetry counters                              |

### ID Generation

All entities use `Date.now().toString(36) + Math.random().toString(36).slice(2)` for unique IDs.

### Data Flow on Note Creation

1. User records audio → Recording saved to file system
2. Whisper.rn transcribes audio → Transcript stored in Note
3. LLM analyzes transcript → Summary, key points, tasks extracted
4. Tasks are created with due dates parsed from natural language
5. Reminders are scheduled via expo-notifications
6. Note is embedded for semantic search
7. Folder classifier suggests or auto-assigns a folder
8. Widget data is synced to iOS widget

## AI System (On-Device)

### LLM — Qwen 2.5 0.5B Instruct

**Model:** `Qwen2.5-0.5B-Instruct-Q4_K_M.gguf` (quantized, ~400 MB)
**Source:** HuggingFace (bartowski)
**Runtime:** llama.rn (native C++ inference on-device)

**Configuration:**

```typescript
{
  model: "<path>",
  use_mlock: true,       // Lock model in memory
  n_ctx: 2048,           // Context window
  n_gpu_layers: 99,      // Full GPU acceleration
}
```

**Inference settings:**

```typescript
{
  n_predict: 512,        // Max tokens to generate
  temperature: 0.3,      // Low temperature for deterministic output
  top_p: 0.9,
  stop: ["</s>", "<|im_end|>", "<|eot_id|>", ...],
}
```

**Download flow:**

- `ensureLlmModel(onProgress)` — Downloads from HuggingFace with progress callback
- Stored at `<documentDirectory>/llama/Qwen2.5-0.5B-Instruct-Q4_K_M.gguf`
- `isLlmModelDownloaded()` checks file existence
- `getContext()` — Lazy-initializes the model (2–5s first load, reused after)
- `releaseContext()` — Frees memory

### Speech-to-Text — Whisper.rn

**Library:** `whisper.rn` v0.6.0

- Runs OpenAI Whisper models entirely on-device
- Real-time transcription of audio recordings
- No internet required

### AI Processing Pipeline

When a voice note is transcribed, `processTranscriptionWithLlm(noteId)` runs:

1. **Transcript Analysis** — Sends transcript to local LLM with structured prompt
   - Extracts: `summary`, `keyPoints[]`, `tasks[]` (with optional `dueDate`, `reminderAt`)
   - JSON response parsed with regex fallback
2. **Task Creation** — For each extracted task:
   - Natural language dates parsed via `parseNaturalDate()`
   - Task created with `linkedNoteId` reference
   - Reminder scheduled if date found
3. **Embedding Generation** — `embedNote(noteId, content)`
   - Uses LLM's embedding capability
   - Stored in AsyncStorage as vector arrays
   - Enables semantic search later
4. **Folder Classification** — `classifyNoteIntoFolder(note, folders)`
   - LLM classifies note into existing folders (or suggests new one)
   - Auto-assigns if confidence ≥ 0.7
   - Otherwise shows suggestion UI to user
   - Also extracts 2–5 topic tags

### Embeddings & Semantic Search

```typescript
type EmbeddingEntry = {
  noteId: string;
  vector: number[]; // Float array from LLM embedding
  contentHash: string; // Simple hash for change detection
};
```

**Search flow (`searchSimilarNotes`):**

1. Generate embedding for search query
2. Compute cosine similarity against all stored note embeddings
3. Return top-K results sorted by score
4. Falls back to keyword matching if LLM unavailable

### Folder Classification

```typescript
type FolderClassification = {
  folderId: string | null; // Matched existing folder
  suggestedFolder: string; // New folder name suggestion
  confidence: number; // 0.0–1.0
  tags: string[]; // 2–5 extracted tags
};
```

- **Auto-assign threshold:** confidence ≥ 0.7 → note moved to folder silently
- **Suggestion threshold:** confidence < 0.7 → shows `pendingFolderSuggestion` UI
- `debouncedRegenerateFolderSummary()` — Regenerates folder AI summary when notes change (5s debounce)

## Natural Language Date Parser

`lib/date-parser.ts` — Custom parser (no external deps) that converts spoken date/time references to ISO strings.

**Supported formats:**

- Relative: `"in 5 minutes"`, `"in 2 hours"`, `"in 3 days"`, `"in 1 week"`
- Named: `"today"`, `"tomorrow"`, `"day after tomorrow"`, `"tonight"`
- Weekdays: `"next Monday"`, `"this Friday"`
- ISO: `"2025-01-15"`
- Natural: `"Jan 15"`, `"January 15 2025"`, `"March 3, 2026"`
- Time words: `"morning"` (9:00), `"noon"` (12:00), `"afternoon"` (14:00), `"evening"` (18:00), `"night"` (21:00), `"midnight"` (00:00)
- Clock: `"7pm"`, `"3:30 PM"`, `"14:00"`
- Ambiguous hours (1–6 without AM/PM) default to PM

**Default time:** If no time specified, defaults to 9:00 AM.

## Notifications System

### Recording Notifications (`lib/recording-notification.ts`)

Persistent notification shown while recording is active:

**Categories:**

- `RECORDING_ACTIVE` → Actions: `Pause`, `Stop & Save`
- `RECORDING_PAUSED` → Actions: `Resume`, `Stop & Save`

**Features:**

- Sticky notification on Android (non-dismissable)
- Action buttons controllable without opening app
- Callback system: `registerActionHandler()` / `unregisterActionHandler()`

### Task Reminder Notifications (`lib/reminder-notifications.ts`)

**Category:** `TASK_REMINDER`
**Actions:**

- `Done` — Marks task complete without opening app
- `Snooze 15m` — Reschedules notification +15 minutes
- `Snooze 1h` — Reschedules notification +1 hour
- Default tap → Opens task detail screen

**Android Channel:** `"reminders"` (HIGH importance, vibration pattern, lock screen visible)

**Reconciliation:** On app launch, `reconcileReminders(tasks)` ensures all pending tasks have valid scheduled notifications — handles cases where notifications were cleared by OS.

**Snooze flow:**

1. Cancel existing notification
2. Update task's `snoozedUntil` and `reminderAt`
3. Schedule new notification at snoozed time
4. Persist updated task to AsyncStorage

## Key User Flows

### 1. Voice Note Creation

```
Record → Stop → Review → Save
                  ↓
         Whisper transcribes (on-device)
                  ↓
         Note created with transcript
                  ↓
         LLM processes in background:
           → Summary generated
           → Key points extracted
           → Tasks extracted + created
           → Dates parsed → Reminders scheduled
           → Embeddings generated
           → Folder classified/suggested
           → Widget synced
```

### 2. AI Chat

```
User types question → Embedding generated for query
                       ↓
              Cosine similarity search across all note embeddings
                       ↓
              Top-K relevant notes retrieved
                       ↓
              LLM generates answer with source citations
```

### 3. Task Reminder Flow

```
Voice note mentions "remind me to X tomorrow at 7pm"
    ↓
LLM extracts: { title: "X", dueDate: "tomorrow at 7pm", reminderAt: "tomorrow at 7pm" }
    ↓
parseNaturalDate("tomorrow at 7pm") → ISO string
    ↓
Task created with linkedNoteId
    ↓
expo-notifications schedules notification
    ↓
At trigger time: notification with [Done] [Snooze 15m] [Snooze 1h]
```

### 4. Folder Auto-Organization

```
Note content → LLM classifies against existing folders
    ↓
If confidence ≥ 0.7 → Auto-assign to folder
If confidence < 0.7 → Show suggestion banner
If no folder matches → Suggest new folder name
    ↓
Tags extracted (2-5 per note)
    ↓
Folder AI summary regenerated (debounced 5s)
```
